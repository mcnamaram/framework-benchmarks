# Dossier: JUnit 6 Maintenance Status

**Source:** Web search — JUnit 6 release status / maintenance timeline — retrieved 2026-10-29.

**Fact:** JUnit 6.0 released Q4 2025; actively maintained. JUnit 4 is maintenance mode (no new features). JUnit 5.14+ (May 2025) is current stable line before JUnit 6.

**Key improvements:** `@Template` injection API, improved `TestExecutionListener`, Kotlin coroutine support, better assertion messages (`assertEquals` with message argument), `@BeforeAll`/`@AfterAll` with `PER_CLASS` lifecycle for shared contexts.
